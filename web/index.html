UN EXPERIMENTO EDUCATIVO

Hola. ¿Qué exploramos?

Un pequeño modelo de caracteres que aprende a partir de ejemplos. Pregunta algo o añade un PDF para ampliar su corpus.

Las respuestas son texto generado carácter por carácter; no es un asistente instruido y puede equivocarse.

Enter para enviar · Shift + Enter para salto de línea

Administración del corpus máximo

Acceso local protegido. Las credenciales iniciales son admin / admin y se exige cambiarlas al primer inicio de sesión. El corpus resultante ensambla primero el núcleo fundacional y después el de personalidad; al final se incorpora el corpus local al entrenamiento.

Ortografía, gramática y concordancia en español; incluye la bitácora sintáctica de contacto.

Turnos Usuario → Pensamiento → Asistente para sobriedad, análisis pausado, seguridad y reconocimiento de límites.

Documentos locales

Puedes previsualizar o eliminar PDFs incorporados. Eliminar un PDF también retira su texto del entrenamiento local.
